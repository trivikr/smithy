# Introducing the Smithy Blog

:::{admonition} TL;DR
:class: tldr

smithy.io now has a blog. It's where we'll post announcements, release
highlights, and practical guides for building with Smithy. Follow along with
the [Atom feed](https://smithy.io/blog/archive/atom.xml).
:::

## Why a blog?

Smithy's [documentation](https://smithy.io/2.0/index.html) explains how
Smithy works, and the [changelog](https://github.com/smithy-lang/smithy/blob/main/CHANGELOG.md)
lists what changed in each release. Neither is a good place to explain *why* a
change matters, show how features fit together, or share what we're working
on next. The blog fills that gap.

## What to expect

- **Announcements** for new projects, tools, and major changes across the
  [smithy-lang](https://github.com/smithy-lang) organization.
- **Release highlights** that walk through notable features with examples and
  link back to the full changelog.
- **Guides** that go deeper than reference documentation, such as choosing
  build plugins or integrating code generators.

## Get involved

Smithy is developed in the open. If there's a topic you'd like us to cover,
[open an issue](https://github.com/smithy-lang/smithy/issues) or start a
discussion on GitHub.
